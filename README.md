# HR Career Hub

A clean, mobile-friendly React + Vite website for students, freshers, and job seekers.

## Setup

```bash
npm install
npm run dev
npm run build
```

## Features

- Free Resume Checker (keyword match score, missing keywords, tips)
- Interview Question Generator by role
- AI Prompt Toolkit preview
- Downloadable HR PDF cards (placeholder alerts)
- SEO blog preview section
- Email lead collection using `localStorage`
- ₹99 Premium Toolkit section with resume templates
